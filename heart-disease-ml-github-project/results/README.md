# Results

Running Week 4, Week 5 or Week 6 will generate result files and figures in this directory.

Generated files may include:
- `baseline_metrics.csv`
- `cross_validation_results.csv`
- `optimization_results.csv`
- `final_metrics.csv`
- `confusion_matrix.png`
- `model_comparison.png`
- `optimization_comparison.png`
- `experiment_log.json`

Result files are generated locally so the repository does not contain fabricated performance numbers.
