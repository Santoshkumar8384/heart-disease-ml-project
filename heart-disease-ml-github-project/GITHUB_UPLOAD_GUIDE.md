# GitHub upload checklist

1. Create a new **public** GitHub repository, e.g. `heart-disease-ml-project`.
2. Upload the contents of this folder.
3. Do not commit passwords, API keys or private information.
4. Do not commit a dataset copy unless its redistribution terms permit it.
5. Wait for GitHub to finish processing the files.
6. Open the repository and copy its URL.
7. Paste that URL into the YuvaIntern GitHub Project URL field for the technical internship tasks.

Example repository URL format:
`https://github.com/YOUR-USERNAME/heart-disease-ml-project`

Do not use `https://github.com/username/project`; that is only the placeholder shown by the internship portal.
